# RoLLM feature extraction
Repository storing the implementation for the paper **[Which Romanian LLMs are the best feature extractors?](RoLLM_feature_extraction.pdf)**. Implementation can be found in the notebook [RoLLM_feature_extraction.ipynb](RoLLM_feature_extraction.ipynb), with supplementary data files used for the experiments.
